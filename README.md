# SQLTreeo T-SQL Debugger downloads

This repository only hosts the release files of **SQLTreeo T-SQL Debugger**, the tool by
[SQLTreeo](https://www.sqltreeo.com/sqldebugger) that steps through stored procedures and functions on SQL Server:
breakpoints, watches, the variables and table variables in view, a query window inside the procedure selected in the call stack, code
changes while it runs, and errors that pause instead of ending the run. The installed application reads the releases
here to offer automatic updates.

- **Download:** the `SqlDebugger-win-Setup.exe` asset of the [latest release](../../releases/latest)
  (Windows 10/11, 64-bit, no .NET installation needed). `SqlDebugger-win-Portable.zip` runs without installing,
  and `SqlDebugger.exe` is the whole application in one file, for computers where nothing may be installed; neither
  updates itself.
- **Product page:** https://www.sqltreeo.com/sqldebugger
- **Support:** https://www.sqltreeo.com

SQLTreeo T-SQL Debugger is commercial software. It is licensed, not sold; the first 30 days are a trial.

The `.nupkg` and `releases.*.json` files are used by the updater and are not meant to be downloaded manually.
